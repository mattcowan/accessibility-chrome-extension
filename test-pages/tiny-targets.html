Tiny Touch Targets

These controls test minimum touch target sizes (WCAG 2.5.5 Level AAA recommends 44×44 CSS px). Look for targets too small, too close together, or nested clickable elements.

❌ Defect (a): 16×16 buttons, 2px gap

Both 16×16px, only 2px apart. Too small and crowded.

⚠ Warn (b): 20×20 button with 30px margin

20×20px but well-isolated. Spacing exception applies; warn level.

⚠ Review (c): Inline text link

This is a paragraph with an inline text link embedded in it. Links inside text are typically exempt from size rules.

✓ Pass (d): 48×48 button

Large button (48×48px) meets WCAG Level AAA recommendations.
