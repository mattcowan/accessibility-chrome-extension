Form Errors

Fixture for Error capture (WCAG 3.3.1, Trusted Tester 5.F; the quoted text supports 3.3.3, TT 5.G). Start the capture, then press each Submit button with the fields empty. data-expect is the grade of the field's finding.

(a) Error tied with aria-describedby, plus aria-invalid

(b) Error text near the field, with no association

(c) A red border only

(d) Error in a role="alert" region, script form with a type="button" button

(e) Focus moves to an error summary

(f) A required field: the browser's own validation blocks the submit
