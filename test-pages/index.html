Accessibility Defect Test Pages

These pages are intentionally broken accessibility-wise. Each page contains specific defects marked with data-expect attributes (fail/warn/review/pass) for testing an accessibility checker Chrome extension. Each defect element is labeled to explain what should be flagged.

Test Pages

  • Motion & Animation Defects
  • Text Spacing & Clipping
  • Focus Indicators
  • Touch Target Sizes
  • Keyboard Traps
  • Media Query Testing
  • Hover-Only Content
  • Reflow at 320px
  • Accessible Names

How to Use

Run each test page through your accessibility checker. Each defect element has a data-expect attribute indicating whether it should fail, warn, or pass. Compare the extension's findings against the expected values to verify coverage.
