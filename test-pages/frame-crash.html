A checker that crashes in a frame

The frame below holds 15,000 open shadow roots, each inside the last. The shared helpers walk into shadow roots by recursion (collectMatching in checkers/lib/findings.js), so Target size and Form labels overflow the stack there. The page itself has no defect. With ?top=1 this page builds the same nest itself, so the check fails in the top frame (the headless runner's case).
